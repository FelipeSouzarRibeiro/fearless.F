## ⚡ Sobre o Projeto

A **FEERLESS** é uma plataforma e portfólio digital criada para consolidar e apresentar serviços de ponta em tecnologia e marketing de alta conversão:

* 🤖 **Automações de Microsserviços & Bots:** Bots inteligentes no WhatsApp (controle financeiro, triagem 24/7, agendamentos), integrações de gateways de pagamento e rotinas sob medida em nuvem.
* 🎬 **Edição de Vídeo & Motion Design:** Retenção nos primeiros 3 segundos, sound design imersivo, color grading e formatos otimizados para Reels, Shorts, Podcasts e comerciais institucionais.
* 💻 **Criação de Sites & Landing Pages:** Interfaces ultra-rápidas, focadas em conversão mobile, SEO estruturado e design moderno.
* 📈 **Tráfego Pago & Performance:** Estratégias orientadas a ROAS real no Google Ads e Meta Ads (Instagram/Facebook) com rastreamento avançado (API de Conversão).
* 📱 **Marketing Digital & Estratégia 360°:** Posicionamento de marca, carrosséis magnéticos, roteiros e funis de vendas.

## 🎨 Design System & Refinamento Visual

O projeto foi construído seguindo rigorosos padrões de agência internacional (*Taste Design* e *Stitch Design System*):

* **Minimalismo Black & White:** Fundo Obsidian Profundo (`#080B08` / `#111A12`) com forte presença e usufruo de Branco Puro (`#FFFFFF`) para botões de ação e contraste tátil.
* **Acentos Cirúrgicos:**
  * **Volt Lime (`#D4FF32`):** Micro-interações, hover e realces dinâmicos.
  * **Emerald (`#10B981`):** Automações financeiras e métricas de resultado.
  * **Electric Blue, Purple & Amber:** Diferenciação visual dos serviços de tecnologia.
* **Hierarquia Tipográfica:**
  * **Display:** *Anton*
  * **Headlines:** *Instrument Sans*
  * **Corpo:** *Plus Jakarta Sans*
  * **Labels & Pills:** *Space Grotesk*
* **Documentação Completa:** Consulte [`.stitch/DESIGN.md`](./.stitch/DESIGN.md).

## 💻 Como Executar Localmente

Como o projeto é construído em HTML, CSS e JavaScript puros (sem dependências pesadas de build), você pode executá-lo de forma instantânea:

1. **Via Navegador:** Dê um duplo clique no arquivo `index.html`.
2. **Via Live Server (VS Code):** Abra a pasta no VS Code e clique em *"Go Live"*.
3. **Via Python:**
   ```powershell
   python -m http.server 8080
   ```
   Acesse: `http://localhost:8080`

## 🌐 Publicação (Deploy)

Para hospedar o site publicamente:
* **GitHub Pages:** Ative nas configurações do repositório (`Settings` → `Pages` → selecione o branch `main` e pasta `/root`).
* **Vercel / Netlify:** Importe este repositório do GitHub e faça deploy automático sem necessidade de configurações adicionais.
