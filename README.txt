FEERLESS — site pessoal
========================

Arquivos:
- index.html   → estrutura da página
- styles.css   → todo o visual (cores, layout, animações)
- script.js    → interações (slides, menu, dropdown, páginas de serviço,
                 linha animada de "Como trabalhamos", vídeo de fundo da
                 página "Edição de vídeo" etc.)
- img/foto-hero.jpeg      → foto de fundo da sessão de slides (Hero)
- video/movimento-arvore.mp4 → vídeo de fundo da página "Edição de vídeo"
  (dentro do menu Serviços)

Como usar:
- Abra index.html num navegador para ver o site localmente.
- Para publicar, é só subir a pasta inteira (mantendo essa estrutura de
  arquivos) em qualquer serviço de hospedagem (Netlify, Vercel, GitHub
  Pages, cPanel etc.).
